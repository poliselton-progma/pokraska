# Покраска — учёт заказов и расходов

Простое приложение в браузере для учёта заказов на покраску, зарплат и расходов.

## Как пользоваться

1. Открой сайт: **https://poliselton-progma.github.io/pokraska/**
2. Добавляй заказы, зарплаты по неделям и расходы.
3. Данные хранятся локально в браузере (localStorage).
4. Можно сделать резервную копию и восстановить её.

## Включить GitHub Pages (если сайт ещё не открывается)

1. Зайди в репозиторий → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **/(root)**
4. Сохрани. Через 1–2 минуты сайт будет доступен.

## Возможности

- Заказы (с суммой, телефоном, безналом −8%)
- Зарплаты за неделю (маляр + 2 помощника)
- Расходы месяца (краска, аренда, электричество, прочее)
- Сводка: прибыль за месяц
- Резервная копия / восстановление
